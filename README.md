# iVDB

IVDB is a vehicle maintenance and service-tracking application for Apple platforms. It is being built with Swift and SwiftUI, using SwiftData for user-owned vehicle and service records and a bundled read-only SQLite catalogue for vehicle specifications, service items and recommended maintenance schedules. The design keeps personal data separate from application-supplied reference data, with future support planned for synchronising user records through iCloud and CloudKit.

This is primarily a hands-on Swift learning project. It is being developed incrementally, with an emphasis on understanding Apple’s frameworks, making deliberate data-model and architecture decisions, and documenting the reasoning behind each stage rather than rushing toward a finished product. The repository is public so others can follow the project’s development, reuse ideas or contribute improvements. IVDB is released under the MIT License.
